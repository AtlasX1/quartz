## 1. 🧩 Fundamentals (Syntax, Variables, Data Types, Operators)

**Ціль:** досконало розуміти синтаксис, типи даних, оператори, приведення типів, а також як JS інтерпретує код.

### 🔹 Синтаксис
- ECMAScript стандарти (ES6+): let, const, arrow functions, modules.
- Різниця між деклараціями та виразами функцій.
- Hoisting — як інтерпретатор піднімає оголошення.

### 🔹 Типи даних
- **Примітиви:** string, number, bigint, boolean, null, undefined, symbol.
- **Reference types:** object, array, function, Map, Set, WeakMap, WeakSet.
- **Типізація:** dynamic typing, implicit/explicit coercion (`==` vs `===`).

### 🔹 Оператори
- Арифметичні, логічні, порівняння, nullish (`??`), optional chaining (`?.`).
- Spread / rest оператори.
- Destructuring об’єктів і масивів.
- Object shorthand, computed properties.

---

## 2. 🔁 Control Flow & Functions

**Ціль:** вміти писати ефективний керований код, розуміти області видимості, контексти та замикання.

### 🔹 Потік виконання
- if/else, switch, for/while/for...of, break/continue, try...catch...finally.
- Логіка короткого замикання (`&&`, `||`, `??`).
- Винятки, генератори (`function*`), ітератори (`next()`).

### 🔹 Функції
- Function Declaration / Expression / Arrow Function.
- Default parameters, rest/spread у параметрах.
- **Closures:** доступ до змінних зовнішньої області.
- **Context (`this`):** втрата контексту, `call`, `apply`, `bind`.
- Higher-order functions (map, filter, reduce, forEach).
- Pure vs impure functions, side effects, immutability.

---

## 3. 🧱 Object-Oriented JavaScript & Prototypes

**Ціль:** знати, як JS реалізує об’єктність без класичної спадковості.

### 🔹 Прототипна модель
- Прототип ланцюга (`[[Prototype]]`), `Object.getPrototypeOf()`, `Object.create()`.
- Ключова різниця між **прототипним** і **класичним** наслідуванням.
- Prototype delegation: пошук властивостей у ланцюгу.
- Конструктори та `new` оператор.

### 🔹 ES6 Classes
- Синтаксичний цукор над прототипами.
- `extends`, `super`, приватні поля (`#privateField`).
- Static методи, class fields, get/set accessors.
- Наслідування, композиція, міксіни.

---

## 4. 🧠 Advanced Language Concepts

**Ціль:** глибоке розуміння роботи рушія JS та його внутрішніх механізмів.

### 🔹 Scope & Execution Context
- Lexical vs Dynamic Scope.
- Global, function, block scopes.
- Execution context stack, variable environment, lexical environment.

### 🔹 Hoisting & TDZ
- Hoisting для функцій, `var`, `let`, `const`.
- Temporal Dead Zone (TDZ) і чому `let` без ініціалізації кидає помилку.

### 🔹 Call Stack & Memory Model
- Як JS виконує код — стек викликів.
- Heap vs Stack, garbage collection.
- Event Loop, microtasks (Promise callbacks), macrotasks (setTimeout, I/O).
- Task queues, Job queues, rendering blocking.

### 🔹 Modules
- CommonJS (`require/module.exports`) vs ES Modules (`import/export`).
- Static vs dynamic imports (`import()`).
- Module resolution, tree shaking, side effects.

---

## 5. ⚡ Asynchronous JavaScript

**Ціль:** впевнено керувати асинхронними операціями, розуміти Event Loop і патерни async flow.

### 🔹 Callback & Promises
- Callback pattern, callback hell, inversion of control.
- Promise lifecycle (`pending → fulfilled/rejected`).
- Chaining, `Promise.all`, `race`, `any`, `allSettled`.
- Error handling через `.catch()`.

### 🔹 Async/Await
- Побудова асинхронних функцій, обробка помилок через `try...catch`.
- Паралельне виконання (`await Promise.all`).
- Використання таймерів (`setTimeout`, `setInterval`, `AbortController`).

### 🔹 Event Loop & Concurrency
- Microtasks (Promises, process.nextTick) vs Macrotasks (setTimeout, fetch).
- Phases of Event Loop: timers, I/O, poll, check, close callbacks.
- Non-blocking I/O — чому JS залишається однопоточним.

## 6. 🧮 Data Structures in JS

**Ціль:** знати внутрішні реалізації та ефективно використовувати вбудовані структури.

### 🔹 Collections
- Arrays — методи (`map`, `filter`, `reduce`, `flatMap`, `findIndex`).
- Sets, Maps, WeakMap, WeakSet — відмінності та сценарії.
- Strings як ітерабельні колекції.

### 🔹 Iterables & Generators
- Символ `Symbol.iterator`, ручна реалізація ітератора.
- `yield`, `return`, `throw` у генераторах.
- Асинхронні генератори (`for await...of`).

### 🔹 Typed Arrays & Buffers
- ArrayBuffer, DataView, Int8Array, Float64Array — робота з двійковими даними.

## 7. 🔐Error Handling & Debugging

**Ціль:** грамотно керувати помилками і вміти діагностувати їх у runtime.

### 🔹 Error Basics
- Error, ReferenceError, TypeError, RangeError, AggregateError.
- `throw` / `try...catch...finally`, custom Error класи.
- Error propagation та stack trace.

### 🔹 Debugging Techniques
- Chrome DevTools, breakpoints, call stack, watch expressions.
- Performance Profiler, Memory Profiler.
- Source maps, логування (`console.table`, `console.time`, `console.trace`).

## 8. 🧰 Functional Programming in JS

**Ціль:** розуміти функціональний стиль програмування та його переваги в чистоті коду.

### 🔹 Основи FP
- Функції як перший клас громадян.
- Pure functions, immutability, referential transparency.
- Higher-order functions, currying, partial application.

### 🔹 Ідіоми FP
- Map/filter/reduce chains.
- Composition (`compose`, `pipe`).
- Avoid side effects, declarative style.

## 9. 🧪 Testing Concepts

**Ціль:** вміти тестувати логіку, асинхронні сценарії та DOM-взаємодію.

### 🔹 Unit Tests

### 🔹 Integration & E2E

## 10. 🚀 Performance & Optimization

**Ціль:** розуміти як оптимізувати виконання JS у браузері або Node.js середовищі.

### 🔹 Оптимізація
- Inline caching, hidden classes (V8 engine optimization).
- Debounce / Throttle / Memoization.
- Avoid blocking main thread, split heavy tasks (Web Workers).

### 🔹 Profiling
- `performance.now()`, `console.profile()`, Performance API.
- Memory leaks detection.
- Lazy loading, code splitting.
