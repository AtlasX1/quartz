## 1. 🧱 Semantic HTML

**Ціль:** створювати структуровані, доступні, пошуково-оптимізовані сторінки з чіткою семантикою.

### 🔹 Основи семантики
- **Документна структура:** `<!DOCTYPE>`, `<html>`, `<head>`, `<body>`.
- **Семантичні теги:** `header`, `main`, `nav`, `section`, `article`, `aside`, `footer`, `figure`, `figcaption`.
- **Текстова семантика:** `strong`, `em`, `abbr`, `time`, `cite`, `blockquote`, `code`, `pre`.
- **Форми:** `label`, `fieldset`, `legend`, `input`, `textarea`, `select`, `datalist`.
- **ARIA roles** — коли використовувати `role="button"` / `role="navigation"` і коли достатньо нативних елементів.

### 🔹 Просунутий рівень (L4)
- Вміти **розробляти layout тільки за допомогою семантичної структури** (без зайвих div).
- Розуміти **document outline**, контекст заголовків (`<h1>`–`<h6>`).
- Знати **DOM API та accessibility tree** — як браузер будує доступну модель документа.
- Володіти техніками **progressive enhancement** і **graceful degradation**.
- Використовувати **microdata / structured data** (`schema.org`, JSON-LD) для SEO.

## 2. 🧩 CSS Fundamentals

**Ціль:** досконале розуміння каскадності, специфічності, наслідування і рендерингу.

### 🔹 Каскадність
- **Cascade Layers (`@layer`)**, порядок пріоритетів: user-agent → user → author → inline → `!important`.
- **Специфічність:** як рахуються бали (inline, id, class, element, universal).
- **Наслідування:** які властивості наслідуються за замовчуванням (`color`, `font`, `visibility`, `line-height`).

### 🔹 Display, Positioning, Flow
- **Normal flow:** block, inline, inline-block, inline-flex.
- **Position:** static, relative, absolute, fixed, sticky.
- **Stacking context:** `z-index`, opacity, transform, flex/grid isolation.
- **Formatting context:** BFC, IFC, FFC (як формується box flow).
- **Visual formatting model:** margin collapsing, box-sizing, overflow handling.

---

## 3. 🧮 CSS Layout Techniques

**Ціль:** створювати адаптивні, масштабовані та складні макети, що стабільно працюють у різних браузерах.

### 🔹 Flexbox
- Основи: main-axis / cross-axis, `justify-content`, `align-items`, `align-content`.
- Advanced: `flex-basis`, `flex-grow`, `flex-shrink`, `order`, `align-self`.
- Реальні патерни: **Holy Grail Layout**, **Sticky Footer**, **Sidebar Layout**, **Equal Height Cards**.

### 🔹 CSS Grid
- Розуміння grid-ліній, фракцій, `minmax()`, `auto-fit`, `auto-fill`.
- Template areas, implicit vs explicit grids.
- Alignment і layering (`grid-area`, `justify-items`, `align-items`).
- Комбінація Flexbox + Grid для складних UI.

### 🔹 Responsive & Adaptive Design
- **Media queries:** `min-width`, `max-width`, `orientation`, `prefers-color-scheme`, `pointer`.
- **Fluid typography:** `clamp()`, `calc()`, `min()` / `max()`.
- **Container queries** — сучасний підхід до компонентної адаптивності.
- Підхід **mobile-first vs desktop-first**.
- **Viewport units (vw, vh, vmin, vmax, svh, lvh)** — поведінка у мобільних браузерах.

## 4. 💅 CSS Architecture & Methodologies

**Ціль:** підтримувані, масштабовані стилі для великих проєктів.

### 🔹 Препроцесори
- **Sass / SCSS / Less:** змінні, міксіни, вкладеність, імпорт, функції.
- Структура SCSS-проєкту (`_variables.scss`, `_mixins.scss`, `_global.scss`, `_components.scss`).
- Використання **PostCSS** для автопрефіксів і оптимізації.

### 🔹 Методології
- **BEM (Block-Element-Modifier)** — іменування, ізоляція стилів.
- **OOCSS, SMACSS, ITCSS** — архітектура шарів стилів.
- **Atomic CSS / Utility-first** (TailwindCSS-підхід): плюси і мінуси.
- **CSS Modules** і **Scoped styles** для компонентного підходу.

### 🔹 Модульність
- Застосування **Design Tokens**, змінних теми (CSS Variables).
- Вміти розробляти **theme switcher** (dark/light mode) через root-level змінні.
- **Stylelint** для стандартизації.

## 5. 🎭 CSS Effects & Animations

**Ціль:** володіння плавними, оптимізованими ефектами, що не порушують продуктивність.

### 🔹 Анімації
- **CSS transitions:** `transition-property`, `duration`, `timing-function`, `delay`.
- **CSS animations:** `@keyframes`, `animation-fill-mode`, `animation-timing-function`.
- **Performance optimization:** використання `transform` та `opacity` замість `top/left`.
- **will-change:** коли і як застосовувати для GPU-акселерації.

### 🔹 Ефекти
- **Filters:** `blur`, `brightness`, `grayscale`, `contrast`.
- **Blend modes:** `mix-blend-mode`, `background-blend-mode`.
- **Clipping & Masking:** `clip-path`, `mask-image`.
- **Parallax, Scroll-based effects** через `scroll-timeline`, `scroll-behavior`.

## 6. ♿ Accessibility (a11y)

**Ціль:** створення сайтів, які доступні для всіх користувачів, включно з тими, що використовують assistive technologies.

### 🔹 Основи
- **ARIA roles**: `role="dialog"`, `role="alert"`, `aria-live`, `aria-expanded`.
- **Keyboard navigation:** `tabindex`, `focus`, `skip-links`, `outline`.
- **Accessible forms:** `label`, `aria-describedby`, валідація з повідомленнями.

### 🔹 Advanced
- **Screen readers:** як вони інтерпретують DOM і ARIA.
- **Focus management:** при модальних вікнах і динамічних елементах.
- **Color contrast:** WCAG 2.1 AA/AAA, інструменти перевірки.
- **Motion sensitivity:** `prefers-reduced-motion` — адаптація анімацій.

## 7. 🚀 Performance Optimization

**Ціль:** глибоке розуміння рендерингу, оптимізація швидкості відображення сторінок.

### 🔹 Рендеринг
- **Critical Rendering Path:** HTML → CSSOM → Render Tree → Layout → Paint → Composite.
- **Reflow vs Repaint:** що викликає кожен процес.
- **Layout Thrashing:** як уникати (batch DOM changes, `requestAnimationFrame`).

### 🔹 Оптимізація
- **Minification, Compression, Caching.**
- **CSS splitting:** `@import`, `critical.css`, lazy loading стилів.
- **Fonts optimization:** `font-display`, preconnect, subset fonts.
- **Image optimization:** `srcset`, `picture`, `WebP`, `AVIF`.

### 🔹 Інструменти
- **Lighthouse**, **PageSpeed Insights**, **WebPageTest**.
- **DevTools Performance tab:** FPS, layout shifts, rendering cost.

## 8. 🧩 SEO & Metadata

**Ціль:** забезпечити високий пошуковий рейтинг і повну індексацію.

### 🔹 HTML SEO Essentials
- Title, meta description, canonical link.
- OpenGraph (Facebook), Twitter Cards.
- Structured data (JSON-LD, schema.org).
- Sitemap.xml, robots.txt.

### 🔹 Core Web Vitals
- **LCP, FID, CLS** — як вони вимірюються і оптимізуються.
- Lazy loading (`loading="lazy"`), preconnect, preload.
- Mobile usability, HTTPS, semantic structure.
