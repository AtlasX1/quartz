Мета: стати експертом у створенні веб-застосунків і API на рівні архітектури, продуктивності, безпеки та масштабування. Покриває Express, Fastify, NestJS, Koa, Hapi, а також REST, GraphQL, gRPC і WebSocket API.

---

## 1) 🧱 Fundamentals of Web Frameworks

**Ціль:** розуміти принципи роботи HTTP-серверів і middleware.

- HTTP lifecycle: request → router → middleware → handler → response.
- Middleware stack: послідовність обробників, `next()`, error handling.
- Body parsing, headers, cookies, query params, form-data.
- Routing: параметри, wildcards, nested routers, route groups.
- Context objects (Koa/Fastify/NestJS).
- Error propagation (try/catch, centralized error middleware).

---

## 2) ⚙️ Express.js (Classics & Pitfalls)

**Ціль:** впевнене володіння Express і розуміння його обмежень.

- Основи: `express()`, `app.use()`, `app.get()`, `req`, `res`.
- Middleware layers, custom middlewares.
- Error-handling middleware (`(err, req, res, next)`).
- Template engines (EJS, Pug), static files.
- Modular routers, composition of apps.
- Performance tuning: compression, helmet, caching.
- Limitations: sync API, lack of schema validation, no DI.

---

## 3) ⚡ Fastify (Performance-Oriented)

**Ціль:** створювати високопродуктивні API з валідацією та типобезпекою.

- `fastify()` core API, routes, plugins.
- Schema-based validation (AJV / JSON Schema).
- Lifecycle hooks: `onRequest`, `preHandler`, `onSend`, `onResponse`.
- Decorators, encapsulation, plugin system.
- Automatic typings inference.
- Benchmarking: Fastify vs Express.
- Integration with TypeScript, Swagger/OpenAPI.

---

## 4) 🧭 NestJS (Enterprise-Level)

**Ціль:** володіти фреймворком корпоративного рівня.

- Modular architecture: `Module`, `Controller`, `Service`, `Provider`.
- Dependency Injection (DI container).
- Request lifecycle: guard → interceptor → pipe → controller → filter.
- Decorators: `@Controller()`, `@Injectable()`, `@UseGuards()`, `@UsePipes()`.
- Interceptors for logging, caching, transformations.
- Exception filters: `@Catch()`.
- Middleware vs Guards vs Interceptors — відмінності.
- Microservices mode (TCP, Kafka, Redis transport).
- Testing modules з `@nestjs/testing`.
- GraphQL integration (Apollo/Code-first), WebSocket gateway, CQRS pattern.

---

## 5) 🧩 Koa, Hapi, AdonisJS, and Others

**Ціль:** знати альтернативні фреймворки та їхні переваги.

- **Koa.js:** middleware-as-promise, async/await-first design.
- **Hapi.js:** configuration over code, plugins, input validation (Joi).
- **AdonisJS:** MVC, ORM (Lucid), lifecycle hooks, dependency injection.
- Коли варто обирати кожен фреймворк: масштаб, архітектура, DX.

---

## 6) 🌐 RESTful API Design

**Ціль:** проєктувати гнучкі, масштабовані REST API з урахуванням best practices.

- CRUD, ресурсна структура (`/users/:id`, `/posts/:id/comments`).
- HTTP methods: GET, POST, PUT, PATCH, DELETE.
- Status codes: 2xx, 4xx, 5xx.
- Idempotency, safe vs unsafe methods.
- Pagination, filtering, sorting.
- Error format: JSON API / custom standard.
- Versioning strategies: URI, headers, content negotiation.
- Rate limiting, caching, ETag, conditional requests.
- OpenAPI/Swagger docs, Postman Collections.

---

## 7) 🧠 GraphQL APIs

**Ціль:** будувати типізовані API з одним endpoint і оптимальним фетчингом даних.

- Schema Definition Language (SDL).
- Queries, Mutations, Subscriptions.
- Resolver map, context, batching (DataLoader).
- Error handling, partial responses.
- Authentication & authorization (directives, middlewares).
- Federation & Stitching.
- Apollo Server, Yoga, Mercurius (Fastify).
- Caching & persisted queries.

---

## 8) 🛰 gRPC & RPC-style APIs

**Ціль:** створювати високопродуктивні двійкові API для сервісної взаємодії.

- Протокол: Protocol Buffers (protobuf).
- Service definitions, stubs, code generation.
- Unary, Server streaming, Client streaming, Bi-directional.
- gRPC vs REST — latency, payload, schema evolution.
- Error model, metadata, deadlines.
- Node.js gRPC libraries (`@grpc/grpc-js`).
- gRPC Gateway (REST proxy).

---

## 9) 🔌 WebSockets & Real-Time APIs

**Ціль:** володіти реальними двосторонніми протоколами.

- **WebSocket:** handshake, frames, message events.
- **Socket.IO:** namespaces, rooms, broadcasting, middleware.
- **SSE (Server-Sent Events)** — односторонній стрім.
- **WebTransport, WebRTC data channels** (next-gen real-time).
- Patterns: presence, typing indicators, live dashboards.
- Scaling real-time apps: Redis Pub/Sub, clustering, sticky sessions.

---

## 10) 🔒 API Security & Auth

**Ціль:** створювати захищені API.

- **Authentication:** JWT, OAuth2, OpenID Connect.
- **Authorization:** RBAC, ABAC, scopes.
- **HTTPS everywhere, CORS, CSP, CSRF.**
- **Input validation:** Joi, Zod, class-validator.
- **Helmet**, **rate limiting**, IP blocking, brute-force protection.
- **Secrets management:** dotenv, HashiCorp Vault, AWS Secrets Manager.
- **Audit logs & request tracing.**

---

## 11) 🚀 Performance & Scaling

**Ціль:** оптимізувати API для тисяч запитів за секунду.

- Benchmarking tools: autocannon, k6, wrk.
- Caching strategies: Redis, CDN, in-memory.
- Connection pooling, Keep-Alive.
- Load balancing, clustering, horizontal scaling.
- Async I/O optimization, streams, backpressure.
- Compression, gzip, Brotli.
- Lazy JSON serialization, streaming responses.

---

## 12) 📡 API Documentation & Developer Experience

**Ціль:** забезпечити якісну DX (Developer Experience).

- Swagger / OpenAPI / Redoc.
- API sandbox: Postman, Hoppscotch.
- Typed API clients: OpenAPI generator, tRPC, Orval.
- Auto-generated SDKs.
- Versioning & changelogs.
- Good error messages and rate-limit headers.

---

## 13) 🧪 Testing & Validation

**Ціль:** перевіряти стабільність API і його контракти.

- **Unit tests:** Jest, Mocha.
- **Integration:** Supertest, Pact (contract testing).
- **E2E:** Cypress, Playwright API tests.
- Mocking HTTP: nock, MSW.
- Schema validation tests (AJV, Joi, Zod).

---

## 14) 🧭 API Gateway, Monitoring & Observability

**Ціль:** інтегрувати API в інфраструктуру підприємства.

- API Gateway (Kong, NGINX, AWS API Gateway, Envoy).
- Logging & tracing: Winston, Pino, OpenTelemetry.
- Metrics: Prometheus, Grafana dashboards.
- Health checks, readiness/liveness probes.
- Distributed tracing & correlation IDs.
- Rate limits, quotas, analytics.
