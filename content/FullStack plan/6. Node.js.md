Мета: стати експертом у Node.js — від базових принципів платформи до архітектури масштабованих серверних застосунків, асинхронності, потоків, безпеки та продуктивності.

---

## 1) 🧱 Core Concepts & Runtime

**Ціль:** глибоко розуміти, як працює Node.js, його архітектуру та внутрішні механізми.

- **V8 Engine:** компіляція JS у машинний код, JIT-оптимізації, event loop.
- **Libuv:** асинхронна I/O-бібліотека, thread pool, черги, timers.
- **Single-threaded event loop:** принцип неблокуючих операцій.
- **Phases of event loop:** timers → pending → idle/prepare → poll → check → close callbacks.
- **Microtasks vs Macrotasks:** promises, nextTick, setImmediate.
- **REPL, process, global objects, console, module system.**

---

## 2) 📦 Modules & Package Management

**Ціль:** розуміти системи модулів і роботу з пакетами.

- **CommonJS (CJS)**: `require`, `module.exports`, кешування модулів.
- **ECMAScript Modules (ESM):** `import/export`, `"type": "module"`, динамічний імпорт.
- **Hybrid environments:** інтероп між CJS та ESM.
- **Package management:** npm, yarn, pnpm — lockfiles, workspaces, semver.
- **Local/Global packages**, **npx**, **scripts**.
- **Монорепозиторії:** Nx, Turborepo, Lerna, pnpm workspaces.

---

## 3) 🧠 Asynchronous Programming

**Ціль:** повне розуміння неблокуючої архітектури Node.js.

- **Callbacks, Promises, Async/Await.**
- **EventEmitter:** створення власних подій, підписка, відписка.
- **Streams:** readable/writable/duplex/transform streams.
- **Pipe & backpressure:** обробка потоків даних без переповнення пам’яті.
- **Worker Threads:** розпаралелювання CPU-bound задач.
- **Child Process, Cluster:** розподіл навантаження.
- **Async Hooks API:** відстеження контексту виконання (useful for tracing).

---

## 4) 🌐 Networking & HTTP

**Ціль:** створювати високопродуктивні мережеві застосунки.

- **HTTP/HTTPS Server:** створення з `http.createServer`, `request`, `response`, `headers`.
- **Middleware pattern:** основа Express/Koa/Fastify.
- **WebSocket API**, `ws`, Socket.io.
- **HTTP2**, `http2.createSecureServer()`.
- **Proxying, reverse proxy (nginx integration)**.
- **Performance headers:** caching, compression, ETag, keep-alive.

---

## 5) 🏗 Frameworks & Architectures

**Ціль:** вміти обирати фреймворк і будувати чисту архітектуру.

- **Express.js:** middleware stack, routers, async handling, error middlewares.
- **Fastify:** schema validation, async hooks, perf vs Express.
- **NestJS:** модульна архітектура, DI, decorators, providers, guards, interceptors.
- **Koa, Hapi, AdonisJS** — альтернатива.
- **BFF-патерн (Backend-for-Frontend)**, **Clean Architecture**, **Hexagonal Architecture**.
- **MVC / Service / Domain-driven structure.**

---

## 6) 🧩 Data Layer & ORM

**Ціль:** володіти роботою з базами даних та ORM.

- **Database drivers:** PostgreSQL, MySQL, MongoDB, Redis, SQLite.
- **ORM/ODM:** Sequelize, Prisma, TypeORM, Mongoose.
- **Connection pools, transactions, migrations.**
- **Query builders:** Knex.js.
- **Caching layers:** Redis, LRU cache, TTL.
- **Streaming large data sets** (наприклад, CSV-парсинг).

---

## 7) 🧰 File System & OS APIs

**Ціль:** знати API Node.js для роботи з системою.

- **`fs` module:** sync/async API, promises, streams, watch.
- **`path`, `url`, `os`, `process`, `cluster`, `worker_threads`.**
- **Buffer, binary data manipulation.**
- **Compression:** zlib, Brotli.
- **File I/O performance:** streams vs readFile, memory usage patterns.

## 8) 🧪 Testing & Debugging

**Ціль:** вміти покривати код тестами та знаходити помилки.

- **Unit Tests:** Jest, Mocha, Vitest.
- **Integration Tests:** Supertest (HTTP APIs), Testcontainers.
- **E2E Tests:** Playwright, Cypress.
- **Debugging:** Node Inspector, Chrome DevTools, `--inspect`, breakpoints.
- **Profiling:** CPU/Heap snapshots, `clinic.js`, `node --trace-deopt`.

## 9) 🔒 Security & Stability

**Ціль:** створювати безпечні сервери та уникати вразливостей.

- **OWASP Top 10** для Node.js.
- **Валідація даних:** Zod, Joi, class-validator.
- **Вразливості пакетів:** `npm audit`, Snyk.
- **Helmet, rate-limiting, CSRF/XSS захист.**
- **Environment Variables:** dotenv, process.env, secrets management.
- **Sandboxing, child_process safety, prototype pollution.**
- **JWT, OAuth2, cookies, sessions.**

## 10) ⚙️ Performance & Scaling

**Ціль:** оптимізувати Node.js застосунки для високих навантажень.

- **Cluster mode** і load balancing.
- **PM2**, **Docker** для менеджменту процесів.
- **Caching:** Redis, in-memory, CDN.
- **Queue systems:** BullMQ, RabbitMQ, Kafka (через kafkajs/nest-kafka).
- **Streaming і backpressure.**
- **Event-driven architecture:** Pub/Sub, CQRS, Event Sourcing.
- **Performance profiling:** Flamegraphs, `perf_hooks`, `async_hooks`.
