Мета: досягти експертного рівня у DevOps-практиках, автоматизації CI/CD, контейнеризації, оркестрації, управлінні інфраструктурою як кодом, моніторингу, логуванні та роботі з Linux.

---

## 1) 🔄 Continuous Integration & Continuous Delivery (CI/CD)

**Ціль:** створювати надійні автоматизовані пайплайни для збірки, тестування, перевірки якості та деплою.

- **Continuous Integration (CI):**
  - Автоматичне збирання коду при кожному push/merge.
  - Виконання тестів, лінтингу, статичного аналізу.
  - Перевірка якості перед злиттям (PR pipelines).
  - Інструменти: GitHub Actions, GitLab CI, Jenkins, CircleCI, Azure DevOps.

- **Continuous Delivery (CD):**
  - Автоматизована доставка у staging або production.
  - Zero-downtime deployment (blue-green, canary releases).
  - Rollbacks та версіонування артефактів.

- **Ключові принципи:**
  - Ідемпотентність деплою.
  - Immutable builds.
  - “Shift-left” testing — рання перевірка якості.
  - Secrets management у пайплайнах (Vault, AWS Secrets Manager).

## 2) 🐳 Containerization (Docker)

**Ціль:** створювати легкі, ізольовані середовища для застосунків.

- **Основи контейнеризації:**
  - Ізоляція процесів через cgroups і namespaces.
  - Порівняння контейнерів і віртуальних машин.
- **Docker концепції:**
  - `Dockerfile`: інструкції для створення образу.
  - `docker build`, `docker run`, `docker compose`.
  - **Image Layers:** кешування та повторне використання.
  - **Best practices:**
    - Менше шарів → менший образ.
    - Використання `alpine`-образів.
    - `.dockerignore` для зменшення розміру.
- **Безпека:**
  - Rootless Docker.
  - Сканування вразливостей (Trivy, Snyk).
- **Використання:** локальний девелопмент, CI/CD, продакшн-деплой.

---

## 3) ☸️ Container Orchestration (Kubernetes)

**Ціль:** автоматизувати розгортання та масштабування контейнерів.

- **Основні концепції:**
  - **Pod:** найменша одиниця виконання (1 або більше контейнерів).
  - **Deployment:** декларативне управління оновленнями.
  - **Service:** мережевий доступ до pod’ів (ClusterIP, NodePort, LoadBalancer).
  - **ConfigMap & Secret:** параметризація конфігурацій.
  - **Ingress:** HTTP-маршрутизація до сервісів.
  - **Namespace:** ізоляція середовищ.
- **Helm:** шаблонізація маніфестів і керування релізами.
- **Scaling:**
  - Horizontal Pod Autoscaler (HPA).
  - Cluster autoscaling.
- **Інструменти:** kubectl, K9s, Lens, ArgoCD, FluxCD.
- **Профі-тема:** Operators, CRDs, GitOps.

## 4) ☁️ Cloud Platforms (AWS / GCP / Azure)

**Ціль:** володіти основними сервісами хмарних платформ для розгортання та масштабування застосунків.

- **AWS:**
  - Compute: EC2, Lambda, ECS, EKS.
  - Storage: S3, EBS.
  - Networking: VPC, Route 53, Load Balancer.
  - Messaging: SQS, SNS, EventBridge.
- **GCP:**
  - Compute Engine, Cloud Run, GKE.
  - Storage: Cloud Storage, BigQuery.
  - Pub/Sub, Cloud Functions.
- **Azure:**
  - App Service, AKS (Kubernetes), Blob Storage.
  - Azure Functions, Event Grid.
- **Multi-cloud & Hybrid:**
  - Використання Terraform або Pulumi для крос-платформного управління.
  - CDN (CloudFront, Cloudflare) та DNS управління.

## 5) 🧱 Infrastructure as Code (IaC)

**Ціль:** автоматизувати управління інфраструктурою через код.

- **Terraform:**
  - Declarative infrastructure-as-code.
  - Providers (AWS, GCP, Azure, Kubernetes).
  - State management, `plan` → `apply` → `destroy`.
  - Modules та reusability.
  - Remote backend (S3, GCS, Terraform Cloud).
- **Ansible:**
  - Configuration management через playbooks.
  - Idempotent tasks і roles.
  - Integration із SSH, WinRM, Docker.
- **Concepts:**
  - Immutable infrastructure.
  - GitOps — зміни через PR у репозиторії.
  - Secrets & variables management (Vault, SSM Parameter Store).
- **Профі-тема:** Policy-as-code (OPA, Sentinel), drift detection, automation pipelines.

## 6) 📊 Monitoring & Logging

**Ціль:** забезпечити видимість і стабільність систем через спостереження.

- **Monitoring:**
  - Time-series metrics: CPU, memory, latency, errors.
  - **Prometheus + Grafana** для збору та візуалізації.
  - Alerts через Alertmanager, PagerDuty.
- **Logging:**
  - **ELK Stack:** Elasticsearch, Logstash, Kibana.
  - Fluentd / Loki для агрегації логів.
  - Structured logs: JSON з correlation IDs.
- **Tracing & Observability:**
  - OpenTelemetry, Jaeger, Tempo.
  - Red/USE метрики: Rate, Errors, Duration / Utilization, Saturation, Errors.
- **APM (Application Performance Monitoring):**
  - New Relic, Datadog, Grafana Cloud.
- **Профі-тема:** SLO/SLA, anomaly detection, distributed tracing.

## 7) 🐧 Linux & Scripting

**Ціль:** вміти керувати системами, автоматизувати завдання та діагностувати проблеми.

- **Команди Linux:**
  - `ps`, `top`, `htop`, `lsof`, `netstat`, `ss`, `df`, `du`, `grep`, `awk`, `sed`, `tail -f`.
  - Systemd: `systemctl`, `journalctl`.
  - Process signals: `kill`, `nohup`, `screen`, `tmux`.
- **Shell Scripting:**
  - Bash variables, functions, loops, conditionals.
  - `cron`, `at`, автоматизація регулярних задач.
  - Використання `jq`, `curl`, `awk` для DevOps-скриптів.
- **Python for automation:**
  - Інструменти: Fabric, Invoke, Paramiko, boto3 (AWS SDK).
  - Інтеграція з CI/CD pipelines.
- **Профі-тема:** hardening, SELinux, user management, filesystem tuning.
