## 1. 🧩 [[Array]]

**Ціль:** досконале розуміння класичних структур даних, їх реалізації, внутрішніх механізмів і застосування.

### 🔹 Основні структури
- **Масиви ([[Arrays]])** — динамічні/статичні, пам’ять, амортизована вартість вставки.
- **Зв’язні списки ([[Linked Lists]])** — однозв’язні, двозв’язні, кругові.
- **Стек ([[Stack & Queue]])** і **черга (Queue)** — принципи LIFO/FIFO, реалізація через масиви або списки.
- **Двостороння черга (Deque)** — оптимізовані вставки/видалення з обох боків.
- **Хеш-таблиці ([[Hash Tables]])**  
  - Колізії: chaining vs open addressing.  
  - Hash functions: властивості, модульні операції, криптографічні.
- **Дерева ([[Trees]])**  
  - Binary, Binary Search Tree (BST), AVL, Red-Black Tree.  
  - Heap (мін/макс), Trie, Segment Tree, Interval Tree.  
  - Traversal: DFS (in/pre/post), BFS.
- **Графи (Graphs)**  
  - Directed/Undirected, Weighted/Unweighted.  
  - Представлення: adjacency list vs matrix.  
  - Cycles, connectivity, shortest paths (Dijkstra, Bellman-Ford), MST (Kruskal, Prim).

### 🔹 Додатково
- **Union-Find (Disjoint Set Union)** — для задач об’єднання множин і пошуку компонент.
- **Bloom Filter, LRU Cache, Skip List, B-tree** — для розуміння advanced структур у базах даних та кешах.
- **Імм’ютабельні структури** — persistent lists/maps, structural sharing (важливо для React/Redux).

## 2. ⚙️ Algorithms & Problem Solving

**Ціль:** розуміти ключові парадигми та вміти обґрунтовувати вибір алгоритму для складних систем.

### 🔹 Базові алгоритми
- **Сортування:** Bubble, Insertion, Merge, Quick, Heap, Counting, Radix.  
  — знати часову/пам’яткову складність, стабільність, оптимальні сценарії.  
- **Пошук:** Linear, Binary, Interpolation, Exponential.  
- **Рекурсія і стек викликів:** tail recursion, рекурсивні дерева.

### 🔹 Парадигми
- **Divide & Conquer** — MergeSort, QuickSort, Binary Search.  
- **Greedy Algorithms** — Huffman coding, Kruskal, coin change.  
- **Dynamic Programming (DP)** —  
  - Top-down vs bottom-up підходи.  
  - Memoization.  
  - Класичні задачі: Fibonacci, Knapsack, Longest Increasing Subsequence, Matrix Chain Multiplication.
- **Backtracking** — N-Queens, permutations, Sudoku.
- **Graph algorithms** — BFS, DFS, Dijkstra, Floyd-Warshall, Bellman-Ford, Kruskal, Prim, A*.  
- **String algorithms** — KMP, Rabin-Karp, Z-function, prefix/suffix arrays, tries.

### 🔹 Алгоритмічні парадигми мислення
- Аналізувати задачу через *state space*, *constraints*, *trade-offs*.  
- Писати псевдокод і аргументувати складність.  
- Розуміти, коли жертвувати точністю заради швидкодії (approximation, heuristics).

## 3. ⏱ Big O Complexity Analysis

**Ціль:** вміти точно аналізувати й оптимізувати час та пам’ять будь-якого алгоритму.

### 🔹 Теоретичні концепції
- **Асимптотична нотація:** O, Ω, Θ — відмінності й застосування.  
- **Амортизований аналіз:** приклад — динамічний масив, hash rehashing.  
- **Складність рекурсій:** Master Theorem (T(n) = aT(n/b) + f(n)).  
- **Аналіз просторової складності:** call stack, heap, memory footprint.  
- **Trade-offs:** час ↔ пам’ять, lookup ↔ insertion.

### 🔹 Профі в L4 рівні повинен:
- Вміти **оцінити складність свого коду “на око”**.  
- Виявляти приховані O(n²) операції (наприклад, вкладені map/filter у JS).  
- Вміти спрощувати до *tight bound* (оптимальної асимптотики).  
- Розуміти складність типових JS-операцій (`Array.push`, `Set.has`, `Map.get`).

## 4. 🧱 Object-Oriented Principles & Aggregation

**Ціль:** глибоке розуміння ООП, SOLID, та проектування гнучких систем через композицію.

### 🔹 Основні принципи ООП
- **Encapsulation, Abstraction, Inheritance, Polymorphism** — у теорії й на практиці.  
- Розуміти *проблеми жорсткої ієрархії* та застосування *композиції* замість наслідування.
- Використовувати **Aggregation / Composition**: передача поведінки через делегування.

### 🔹 SOLID принципи
- **Single Responsibility** — один обов’язок на клас.  
- **Open/Closed** — відкритий для розширення, закритий для змін.  
- **Liskov Substitution** — підкласи мають заміняти базовий без порушень логіки.  
- **Interface Segregation** — не створювати “fat interfaces”.  
- **Dependency Inversion** — залежність від абстракцій, не реалізацій.

### 🔹 Design Patterns (GoF)
- **Creational:** Factory, Builder, Singleton, Prototype.  
- **Structural:** Adapter, Decorator, Proxy, Composite, Facade.  
- **Behavioral:** Strategy, Observer, Command, Chain of Responsibility.  
- Розуміти їх реалізацію **на TypeScript**, без “Java-підходів”.

### 🔹 Архітектурні принципи
- Чіткі шари: Presentation / Business / Data.  
- Вміння створити DI контейнер або використовувати готовий (InversifyJS, NestJS).  
- Розуміння GRASP-принципів (High Cohesion, Low Coupling).

## 5. ⚡ Concurrency & Multithreading Concepts

**Ціль:** розуміння паралельного виконання, потоків, асинхронності та синхронізації.

### 🔹 Основи
- **Модель паралелізму:** процеси, потоки, черги повідомлень.  
- **Проблеми конкурентності:** race conditions, deadlocks, starvation.  
- **Синхронізація:** locks, semaphores, mutexes, monitors.  
- **Thread Pools** — переваги над створенням нових потоків.

### 🔹 У контексті Node.js / JS
- **Event Loop:** макрозавдання (I/O, timers) vs мікрозавдання (Promises, process.nextTick).  
- **Async/Await, Promise.all, race, allSettled** — керування паралельністю.  
- **Worker Threads** — багатопоточність у Node.js.  
- **Cluster mode** — використання кількох ядер CPU.  
- **Message passing і SharedArrayBuffer**.

### 🔹 Advanced теми
- **Lock-free structures** — atomic operations, compare-and-swap.  
- **Concurrency patterns:** Producer-Consumer, Pipeline, Fan-out/Fan-in.  
- **Asynchronous design:** event queues, scheduling, debouncing, throttling.

## 6. 🌐 Networking Basics

**Ціль:** розуміти, як працюють мережі, протоколи і взаємодія клієнт–сервер на низькому рівні.

### 🔹 Моделі та концепції
- **OSI Model (7 шарів)** — що робить кожен шар (фізичний → прикладний).  
- **TCP/IP Stack (4 шари)** — як він реалізований у реальних мережах.  
- **IP адресація:** IPv4, IPv6, маски, CIDR, маршрутизація.  
- **DNS:** резолюція доменів, CNAME, TTL.  
- **Ports & Sockets:** роль портів, ephemeral ports, сокетне з’єднання.

### 🔹 Протоколи
- **HTTP:** версії 1.1, 2, 3 (QUIC), keep-alive, headers, chunked encoding.  
- **HTTPS & SSL/TLS:** handshake, сертифікати, public/private keys.  
- **WebSocket, SSE, MQTT:** двостороння комунікація.  
- **FTP, SSH, SMTP:** базове розуміння старших протоколів.

### 🔹 Додатково
- **Routing та NAT:** як маршрутизатори пересилають пакети.  
- **Firewall і Proxy:** різниця між рівнями (L3, L4, L7).  
- **Latency vs Bandwidth vs Throughput:** що реально впливає на швидкість.  
- **CDN та кешування:** як зменшити час відповіді.
