**Network Software** — це програмне забезпечення, яке допомагає **керувати мережею**, **забезпечувати зв'язок між пристроями**, **контролювати доступ** та **аналізувати трафік**. Воно є важливою частиною інфраструктури, особливо для DevOps, адже допомагає автоматизувати, діагностувати та моніторити мережі.

## 🧰 **1. Мережева підтримка в операційній системі**

Більшість ОС (Linux, Windows, macOS) мають вбудовані мережеві функції:

- Підтримка TCP/IP
- DHCP-клієнт
- DNS-резолвер
- Конфігурація маршрутизаторів, брандмауерів, проксі

📌 Наприклад, у Linux є:
- `ip`, `ss`, `ping`, `traceroute`, `netstat`, `iptables`, `nftables`
- служби: `NetworkManager`, `systemd-networkd`

---

## 🧪 **2. Консольні утиліти для діагностики та аналізу**

Це твої "очі" в мережі 👀

|Утиліта|Призначення|
|---|---|
|`ping`|Перевірка доступності хоста через ICMP|
|`traceroute` / `tracert`|Шлях проходження пакетів|
|`ip` / `ifconfig`|Показує мережеві інтерфейси|
|`netstat` / `ss`|Активні з'єднання, порти|
|`dig`, `nslookup`|DNS-запити|
|`nmap`|Сканування хостів та портів|
|`tcpdump`|Аналіз мережевого трафіку|
|`curl`, `wget`|Відправлення HTTP-запитів|
|`iptables` / `nft`|Налаштування фаєрвола (Linux)|

---

## 📦 **3. Серверне програмне забезпечення (Network Services)**

|Тип сервера|Програмне забезпечення|
|---|---|
|**DNS**|`bind9`, `dnsmasq`, `CoreDNS`|
|**DHCP**|`isc-dhcp-server`, `dnsmasq`|
|**Web**|`Apache`, `Nginx`, `Caddy`|
|**FTP**|`vsftpd`, `proftpd`, `pure-ftpd`|
|**SSH**|`OpenSSH` (сервер та клієнт)|
|**VPN**|`OpenVPN`, `WireGuard`, `StrongSwan`|
|**Proxy**|`Squid`, `HAProxy`, `Nginx`|
|**Load Balancer**|`HAProxy`, `Nginx`, `Traefik`|

📌 Приклад запуску web-серверу на Nginx:
```
sudo apt install nginx sudo systemctl start nginx
```

## 🌐 **5. Веб-інтерфейси керування**

- Домашні/офісні роутери мають веб-інтерфейси (зазвичай доступ за IP типу `192.168.0.1`).
- Вони дозволяють:
    - Переглядати пристрої в мережі
    - Змінювати Wi-Fi пароль
    - Встановлювати фільтрацію
