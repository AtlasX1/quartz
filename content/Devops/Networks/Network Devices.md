## 🧩 **Основні мережеві пристрої**

---

### 1. 🔌 **Комутатор (Switch)**

**Призначення:** з’єднує пристрої в межах однієї **локальної мережі (LAN)** і пересилає дані тільки туди, де вони потрібні.

🧠 Розуміє **MAC-адреси** і будує таблицю відповідності портів і пристроїв.

📦 Приклад:
```
PC1 → Switch → PC2
```

> Якщо PC1 надсилає дані PC2, Switch передає тільки на порт, до якого підключено PC2.

---

### 2. 🌐 **Маршрутизатор (Router)**

**Призначення:** з’єднує **різні мережі** (наприклад, домашню LAN з Інтернетом).

🧠 Працює з **IP-адресами**, приймає рішення на основі маршрутів.

📦 Приклад:
```
Домашній ПК → Router → Інтернет
```

> Якщо твій ПК хоче зайти на сайт, роутер передає трафік в Інтернет.

---

### 3. 📡 **Точка доступу (Access Point)**

**Призначення:** забезпечує **бездротове підключення** пристроїв до мережі (Wi-Fi).

🧠 Часто вбудована в домашні маршрутизатори.

📦 Приклад:

```
Смартфон → Access Point → Switch → Router
```

> Точка доступу приймає сигнал Wi-Fi від смартфона і передає його далі мережею.

---

### 4. 🌍 **Модем (Modem)**

**Призначення:** перетворює сигнали з мережі провайдера в цифровий сигнал для комп’ютера.

🧠 Використовується для підключення до DSL, кабельного чи оптичного Інтернету.

📦 Приклад:
```
Інтернет (від провайдера) → Модем → Router → Комп’ютер
```

---

### 5. 🔥 **Мережевий екран (Firewall)**

**Призначення:** фільтрує трафік між мережами згідно з політиками безпеки.

🛡️ Захищає мережу від несанкціонованого доступу, вірусів, сканувань тощо.

📦 Буває:

- Програмний (`ufw`, `iptables`, Windows Firewall)
- Апаратний (окрема залізка або вбудований у маршрутизатор)

---

### 6. 📊 **Load Balancer (Балансувальник навантаження)**

**Призначення:** розподіляє запити між кількома серверами.

🧠 Використовується в хмарних середовищах, веб-додатках.

📦 Приклад:
```
Клієнти → Load Balancer → [Web Server 1, Web Server 2, Web Server 3]
```

---

## 🧠 Порівняльна табличка

|Пристрій|Рівень OSI|Працює з|Основне завдання|
|---|---|---|---|
|Switch|2 (канальний)|MAC-адресами|Передає дані в LAN|
|Router|3 (мережевий)|IP-адресами|З’єднує мережі, маршрутизує|
|Access Point|2/1|Wi-Fi сигнал|Дає бездротовий доступ|
|Modem|1 (фізичний)|Сигнали|Підключає до Інтернету|
|Firewall|3–7|IP/порти|Захист, фільтрація|
|Load Balancer|4/7|TCP/HTTP|Розподіл трафіку|
**Network segment (мережевий сегмент)** — це частина комп’ютерної мережі, в якій усі пристрої можуть безпосередньо спілкуватися один з одним на канальному рівні (Layer 2 моделі OSI). Це як кімната в будинку: усі, хто в ній, можуть чути одне одного без допомоги посередників.

### 🔹 Основні характеристики сегменту мережі:

- Всі пристрої в одному сегменті знаходяться в **одній підмережі IP**.
    
- Між пристроями немає маршрутизаторів — лише **комутатори (switches)** або **концентратори (hubs)**.
    
- Сегменти обмежують **ширину каналу**, тобто кількість пристроїв у сегменті впливає на продуктивність.
    
- Сегменти часто відокремлюються **маршрутизаторами (routers)** або **VLANами**.
    

---

### 🔸 Приклад:

Уявімо офіс із трьома поверхами:

- На кожному поверсі стоїть свій комутатор (switch).
    
- Усі пристрої, підключені до одного комутатора, утворюють **один мережевий сегмент**.
    
- Щоб пристрій з 1 поверху міг спілкуватися з пристроєм на 2 поверсі, потрібно використовувати маршрутизатор або налаштувати VLAN.
    

---

### 🔧 Навіщо це потрібно?

- **Ізоляція трафіку**: щоб зменшити конфлікти або захистити частини мережі.
    
- **Підвищення безпеки**: поділ на сегменти дозволяє обмежити доступ до певних ресурсів.
    
- **Оптимізація продуктивності**: менше пристроїв у сегменті — менше колізій і краща швидкість.
