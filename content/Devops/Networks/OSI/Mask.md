## 🧠 **Що таке маска мережі (network mask)?**

**Маска мережі** — це спеціальне число, яке визначає, **яка частина IP-адреси є адресою мережі**, а **яка частина — адресою хоста (пристрою)**.

---

## 🔢 **Будова IP-адреси (IPv4)**

- IPv4-адреса має **32 біти**, які зазвичай записують у вигляді 4 чисел:


```
192.168.1.10  → 11000000.10101000.00000001.00001010
```

- Маска також має 32 біти:

```
255.255.255.0 → 11111111.11111111.11111111.00000000
```

> У масці **"1" означає мережу**, а **"0" — хоста**

---

## 🧮 **Як працює маска?**

Маска виконує **логічне І (AND)** між IP-адресою і маскою:
```
192.168.1.10
AND 255.255.255.0
=   192.168.1.0   ← це адреса мережі
```

---

## 🔍 **Формат маски (CIDR)**

Часто маску записують у скороченому вигляді — **CIDR-нотація** (Classless Inter-Domain Routing):

```
192.168.1.10/24
```

`/24` означає, що **перші 24 біти** — це мережа (`255.255.255.0`)

|CIDR|Маска|Кількість хостів|
|---|---|---|
|/8|255.0.0.0|~16 млн|
|/16|255.255.0.0|~65 тис.|
|/24|255.255.255.0|254|
|/30|255.255.255.252|2 (технічні мережі точка-точка)|

---

## 🧮 **Як порахувати кількість хостів?**

Формула:

CopyEdit

```
Кількість хостів = 2^(кількість нулів у масці) - 2
```
(-2 тому що одна адреса — **мережева**, інша — **broadcast**)
Наприклад, `/24` → 8 нулів → 2^8 - 2 = 254 хости

---

## 📦 **Приклад**


```
IP:    192.168.10.17
Mask:  255.255.255.0 (/24)

Мережева адреса:   192.168.10.0
Перший хост:       192.168.10.1
Останній хост:     192.168.10.254
Broadcast-адреса:  192.168.10.255
```

## 🔧 **Практичні інструменти**

### ✅ Перевірити IP і маску:


```bash
ip a
```

### ✅ Обчислити вручну:


```bash
ipcalc 192.168.10.17/24
```

### ✅ Вивести таблицю маршрутів:

```bash
ip route
```

---

## 🧠 Чому маска важлива?

- Розмежовує IP-простір на **мережі і підмережі**
- Дозволяє створювати **ізольовані сегменти** (наприклад, `frontend`, `backend`)
- Дає змогу **оптимізувати маршрутизацію**
- Необхідна для роботи з:
    - **Firewall**
    - **VPN**
    - **Docker / Kubernetes (CIDR для кластеру)**
    - **Хмарні платформи (VPC, Subnet)**
