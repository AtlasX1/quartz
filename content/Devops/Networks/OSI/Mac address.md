**MAC-адреса (Media Access Control address)** — це **унікальний ідентифікатор мережевого інтерфейсу**, який використовується на **канальному рівні (2-й рівень OSI)** для обміну даними **в межах локальної мережі (LAN)**.

## 📘 **Що таке MAC-адреса простими словами**

Уяви, що кожен комп’ютер, телефон, роутер або інший пристрій з мережею — це **поштовий ящик**.  
**MAC-адреса — це його унікальний номер**, який дозволяє комутаторам точно знати, **куди саме в мережі LAN направляти кадри даних**.

---
## 🔢 **Формат MAC-адреси**

- Складається з **48 біт** (6 байт)
- Записується у 16-річній системі, розділяється двокрапками або дефісами:

📌 Приклади:
`00:1A:2B:3C:4D:5E 00-14-22-01-23-45`

---

## 🏷️ **Структура MAC-адреси**

|Частина|Що означає|
|---|---|
|Перші 3 байти|**OUI (Organizationally Unique Identifier)** — виробник|
|Останні 3 байти|Унікальний серійний номер|

📌 Наприклад:  
`00:1A:2B` — Apple, `00:0C:29` — VMware

---

## 🧭 **Де і як використовується MAC-адреса**

|Застосування|Пояснення|
|---|---|
|📡 **Ethernet / Wi-Fi**|Використовується для доставки кадрів|
|📍 **Комутатори (Switch)**|Зберігають MAC-адреси в таблицях, щоб знати, куди відправляти пакети|
|🧩 **ARP (Address Resolution Protocol)**|Перетворює IP-адресу в MAC у локальній мережі|
|🔐 **Фільтрація доступу**|Деякі Wi-Fi-мережі дозволяють тільки відомі MAC-адреси|
|🧪 **Діагностика мережі**|Аналіз трафіку (`tcpdump`, `wireshark`) показує MAC-адреси|

---

## 🔧 **Як подивитись MAC-адресу (в Linux)**

```bash
ip link
```
Або так:
```bash
ip a | grep ether
```

---

## 🎭 **MAC Spoofing (підміна MAC-адреси)**

Можна змінити MAC-адресу вручну (наприклад, для тестування або обхід фільтрації):

```
sudo ip link set dev eth0 down
sudo ip link set dev eth0 address 00:11:22:33:44:55
sudo ip link set dev eth0 up
```

## 🧠 Для DevOps важливо:

- 📦 Налагоджувати підключення в Docker/Kubernetes (там теж є MAC!)
- 🛡️ Розуміти, як працює ARP, і як мережа "знаходить" MAC
- 🧪 Аналізувати проблеми в мережі через `tcpdump`, `wireshark`
