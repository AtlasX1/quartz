**Encapsulation (Інкапсуляція)** — це **основна концепція мережевої моделі OSI та TCP/IP**, яка означає **“згортання” даних з одного рівня у структуру вищого рівня, додаючи службову інформацію (заголовки)**.

Простіше кажучи:

> Інкапсуляція — це **процес обгортання даних у «конверти»**, щоб їх можна було **доставити по мережі від одного пристрою до іншого**.


## 📦 **Що відбувається під час інкапсуляції?**

Коли ти, наприклад, надсилаєш HTTP-запит (`GET /index.html`) — цей запит проходить **кожен рівень OSI**, і **кожен рівень додає свій заголовок (header)**:

### 🧱 Приклад (зверху вниз):

|Рівень|Що додається|
|---|---|
|7. Application|HTTP-запит|
|6. Presentation|Кодування / шифрування (TLS header)|
|5. Session|Дані про сесію|
|4. Transport|TCP-заголовок (порти, контрольна сума)|
|3. Network|IP-заголовок (адреси відправника і отримувача)|
|2. Data Link|MAC-адреси, кадр Ethernet|
|1. Physical|Біти по кабелю або Wi-Fi|

> 📦 У підсумку: **дані згорнуті в декілька шарів**, як "матрьошка".

---

## 🧠 **Навіщо потрібна інкапсуляція?**

|Перевага|Пояснення|
|---|---|
|📤 Організація|Дані розділені по рівнях, легко контролювати|
|🎯 Адресація|IP і MAC-адреси додаються на відповідних рівнях|
|🔒 Безпека|TLS/SSL шифрують лише на певному рівні|
|📦 Стандартизація|Кожен рівень "робить свою справу", незалежно від інших|

---

## 🔁 **Деінкапсуляція (Decapsulation)**

Коли дані **доходять до одержувача**, вони проходять **у зворотному порядку** — **деінкапсуляція**:

1. Приймається фізичний сигнал
2. Видаляється Ethernet-заголовок
3. Розпаковується IP-заголовок
4. Обробляється TCP-заголовок
5. І нарешті дані передаються HTTP-серверу

---

## 📘 Візуально (матрьошка-пакет):

```pgsql
[Ethernet Header [
  IP Header [
    TCP Header [
      TLS Header [
        HTTP Data
      ]
    ]
  ]
]]

```

## 🛠️ **DevOps-практика**

- 📦 **tcpdump / Wireshark** — дозволяє побачити всі рівні інкапсуляції
- 🔧 Налаштування **VPN**: це ще одна інкапсуляція — всередині IP → ще один IP!
- 📤 Робота з **Docker / Kubernetes**: інкапсуляція в оверлейних мережах
- 🔐 **HTTPS = інкапсульований HTTP + TLS**
