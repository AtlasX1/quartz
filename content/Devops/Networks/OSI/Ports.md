**Порт (port)** — це **логічна адреса на транспортному рівні (OSI рівень 4)**, яка використовується для **розділення сервісів на одному пристрої**. Завдяки портам один сервер може обслуговувати одночасно багато різних типів запитів: веб, пошту, SSH тощо.


---

## 🧠 **Що таке порт в комп'ютерних мережах?**

**Порт** — це **16-бітове число (0–65535)**, яке **ідентифікує конкретний процес/сервіс** на пристрої.

📌 **Порт + IP-адреса = унікальна адреса процесу**  
(так зване **socket pair**)

Наприклад:

`192.168.1.100:80   → HTTP-сервер 192.168.1.100:22   → SSH`

---

## 🧩 **Як працюють порти**

Коли ти відкриваєш сайт:
1. Твій комп’ютер відкриває **випадковий клієнтський порт** (наприклад, 54321)
2. Встановлює з'єднання з **портом 80 (HTTP)** або **443 (HTTPS)** сервера
3. Сервер відповідає на цей порт

📦 Приклад TCP-з’єднання:

`Клієнт: 192.168.1.10:54321 Сервер: 142.250.186.14:443`

---

## 🧮 **Діапазони портів**

|Діапазон|Назва|Призначення|
|---|---|---|
|`0–1023`|📘 **Well-known ports**|Системні сервіси (HTTP, SSH, DNS…)|
|`1024–49151`|📘 **Registered ports**|Програми та сервіси (PostgreSQL, MySQL…)|
|`49152–65535`|🌀 **Dynamic/private ports**|Тимчасові (клієнтські) з'єднання|

---

## 🌐 **Поширені номери портів**

|Сервіс|Порт|Протокол|
|---|---|---|
|HTTP|80|TCP|
|HTTPS|443|TCP|
|SSH|22|TCP|
|FTP|21|TCP|
|DNS|53|UDP/TCP|
|DHCP|67/68|UDP|
|SMTP (пошта)|25 / 587|TCP|
|MySQL|3306|TCP|
|PostgreSQL|5432|TCP|

## 🔧 **Команди для перегляду портів (Linux)**

### 📍 Переглянути відкриті порти:
```bash
ss -tuln
```
- `-t` TCP
- `-u` UDP
- `-l` лише ті, що слухають
- `-n` не резолвити імена

### 🔍 Перевірити, хто слухає порт:

```bash
sudo lsof -i :80
```

### 🛡️ Перевірка ззовні:

```bash
nmap -p 22,80,443 your-ip
```

---

## 🛠️ **Порти в Docker/Kubernetes**

- Docker-контейнери мають **свої порти**, які **мапляться на хостові**:
```bash
docker run -p 8080:80 nginx
```

- У Kubernetes — **сервіси (services)** відкривають порти для доступу до подів

## 🧠 Навіщо порти DevOps-інженеру?

- 🔒 Налаштування firewall (які порти відкриті?)
- 🚀 Розгортання сервісів (який порт використовує nginx, postgres…)
- 🧪 Тестування (ping, curl, netcat)
- 📦 Балансування навантаження (наприклад, HAProxy, Nginx LB)
- ☁️ Cloud Security Groups / VPC — відкриття портів у хмарі (AWS, GCP)
