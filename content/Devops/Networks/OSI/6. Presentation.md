**Presentation Layer (Рівень подання)** — це **6-й рівень моделі OSI**, і хоч його часто не видно напряму, він **вкрай важливий** для забезпечення того, щоб **дані були зрозумілі обом сторонам комунікації**.

## 🎯 **Основна роль Presentation Layer**

Це рівень, який відповідає за:

|Функція|Пояснення|
|---|---|
|🔄 **Форматування даних**|Перетворення даних у формат, зрозумілий одержувачу|
|🗜️ **Стиснення**|Зменшення розміру даних для передачі|
|🔐 **Шифрування / дешифрування**|Захист інформації при передачі|
|🗣️ **Перетворення форматів**|Наприклад, текст з Unicode у ASCII, або JSON у XML|
|🔧 **Уніфікація кодування**|Вирівнювання різних форматів між платформами|

---

## 📦 **Як працює Presentation Layer?**

### 📤 Відправник:

1. Застосунок створює дані
2. Presentation Layer **шифрує**, **стискає**, **перетворює**
3. Далі передає на рівень **Session → Transport → Network…**

### 📥 Одержувач:
1. Отримує бітовий потік
2. Presentation Layer **дешифрує**, **розпаковує**, **перетворює**
3. Передає зрозумілі дані застосунку

| Функція               | Приклади                 |
| --------------------- | ------------------------ |
| 🔐 Шифрування         | SSL/TLS, SSH             |
| 🗜️ Стиснення         | gzip, Brotli, JPEG, MPEG |
| 📂 Формат даних       | XML, JSON, YAML, CSV     |
| 🈚 Кодування символів | UTF-8, ASCII, Unicode    |
| 📸 Бінарні формати    | PNG, PDF, DOCX           |
|                       |                          |

---
## 🔐 **Шифрування: TLS/SSL**

Коли ти заходиш на `https://example.com`:
- Presentation Layer шифрує твої запити через **TLS**
- Дані стають **захищеними від перехоплення**
- Тільки сервер (і клієнт) можуть їх розшифрувати

📌 В цьому випадку, **HTTPS = HTTP + TLS (Presentation Layer)**

---
## 🧠 **Presentation vs Application Layer**

|Ознака|Presentation|Application|
|---|---|---|
|Призначення|Обробка формату/захисту|Взаємодія з користувачем|
|Приклади|TLS, JPEG, UTF-8|HTTP, FTP, SMTP|
|Видимість|Не завжди явна|Видимий для користувача|

## 📘 DevOps-приклади використання

|Завдання|Опис|
|---|---|
|🔐 Налаштування HTTPS|Робота з TLS/SSL сертифікатами (Nginx, Apache)|
|🧾 Обробка логів|Розбір JSON, XML|
|📦 CI/CD пайплайни|Стиснення артефактів (gzip, zip)|
|📊 Моніторинг даних|Розбір форматів метрик (Prometheus -> JSON/YAML)|

## 🔚 Підсумок

**Presentation Layer**:
- **Форматує**, **шифрує**, **стискає**
- Забезпечує **універсальність та безпеку передачі**
- Особливо важливий при роботі з **веб-технологіями, API, TLS**
