**Transport Layer (Транспортний рівень)** — це **4-й рівень моделі OSI**, і він надзвичайно важливий, бо відповідає за **передачу даних "від процесу до процесу"** з урахуванням **надійності, порядку, цілісності та контролю потоку**.

Це саме той рівень, де працюють **TCP** і **UDP** — ключові протоколи для DevOps-інженера.
## 🧠 **Що робить Transport Layer?**

|Функція|Пояснення|
|---|---|
|📤 Передача даних між додатками|Наприклад, від твого браузера до веб-сервера|
|🛡️ Надійність|Перевірка доставки, корекція помилок|
|🚦 Контроль потоку|Щоб відправник не «переповнив» одержувача|
|📦 Сегментація|Розбиває дані на шматки — **сегменти**|
|🎯 Мультиплексування|Кілька процесів можуть використовувати одне з’єднання (порти)|

---

## 🔢 **Порти (Ports)**

Кожен процес/сервіс в системі використовує **порт** для комунікації.

📌 **Формат з’єднання:**

`<IP-адреса>:<порт>`

|Тип порту|Діапазон|Приклади|
|---|---|---|
|Well-known|0–1023|80 (HTTP), 443 (HTTPS), 22 (SSH)|
|Registered|1024–49151|3306 (MySQL), 5432 (PostgreSQL)|
|Dynamic|49152–65535|Використовуються клієнтами|

---

## 🔗 **Протоколи транспортного рівня**

### 🔹 **TCP (Transmission Control Protocol)**

- **Надійний**, **орієнтований на з’єднання**
- Підтвердження отримання (ACK)
- Відновлення втрачених пакетів
- Гарантує **порядок** доставки

📦 Приклад використання:
- HTTP/HTTPS
- SSH
- FTP
- SMTP

📘 3-Way Handshake (перед передачею):
```
1. SYN →
2. ← SYN-ACK
3. ACK →
```

### 🔹 **UDP (User Datagram Protocol)**

- **Ненадійний**, **без з’єднання**
- Без перевірки доставки, без контролю помилок
- Дуже швидкий, легкий

📦 Приклад використання:
- DNS
- VoIP
- Відеострімінг (YouTube, Zoom)

---
## 📦 **Формат TCP-сегменту (спрощено)**

```
| Source Port | Destination Port |
| Sequence Number |
| Acknowledgment Number |
| Flags (SYN, ACK, FIN) |
| Data |
```

## 🧪 **Практика з TCP/UDP (Linux)**

### 📥 Переглянути активні з’єднання:

```bash
ss -tuln
```
### 📤 Відправити HTTP-запит через TCP:

```bash
curl http://example.com
```
### 📡 Відправити DNS-запит через UDP:

```bash
dig @8.8.8.8 google.com
```

## 🔍 **Порівняльна таблиця TCP vs UDP**

|Характеристика|TCP|UDP|
|---|---|---|
|Надійність|✅ Так|❌ Ні|
|Контроль порядку|✅|❌|
|Підтвердження (ACK)|✅|❌|
|Швидкість|Повільніше|Швидше|
|Використовується для|HTTP, SSH, FTP|DNS, VoIP, відео|

## 🧠 Навіщо це знати DevOps?

- Ти будеш відкривати і захищати **порти в firewall**
- Налаштовувати **брандмауери, балансувальники навантаження**
- Аналізувати **проблеми з мережею або доступом**
- Оптимізувати **передачу даних між мікросервісами**
