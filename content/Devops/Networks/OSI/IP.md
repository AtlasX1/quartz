## 🧠 **Що таке IP-адреса?**

**IP-адреса (Internet Protocol Address)** — це **унікальний числовий ідентифікатор пристрою в мережі**, який дозволяє:
- знайти пристрій у мережі,
- відправити йому дані,
- отримати від нього відповідь.

Це як адреса будинку в місті 🌍 — щоб доставити лист, треба знати, куди саме його надсилати.

---

## 🔢 **Види IP-адрес**

### 🔹 **IPv4** — найпоширеніший формат

- Складається з **4 октетів по 8 біт** (разом 32 біти)
- Запис: **192.168.0.1**
- Діапазон: від `0.0.0.0` до `255.255.255.255`

📦 **Приклад IPv4**:

`192.168.1.10`

---

### 🔹 **IPv6** — новіший стандарт

- Складається з **128 біт**
- Запис у шістнадцятковому форматі:

`fe80::1ff:fe23:4567:890a`

Потрібен через **нестачу IPv4-адрес**

---

## 📘 **Типи IP-адрес**

|Тип|Опис|Приклад|
|---|---|---|
|**Публічна (public)**|Доступна з Інтернету|8.8.8.8|
|**Приватна (private)**|Використовується в локальних мережах|192.168.0.0/16|
|**Статична**|Видається вручну, не змінюється|Веб-сервер|
|**Динамічна**|Видається DHCP-сервером автоматично|Звичайний ПК|
|**Loopback**|Адреса "самого себе"|127.0.0.1|

---

## 🌐 **Приватні діапазони IPv4 (не виходять в Інтернет напряму)**

|Діапазон|CIDR|Приклад|
|---|---|---|
|10.0.0.0 - 10.255.255.255|/8|10.1.1.1|
|172.16.0.0 - 172.31.255.255|/12|172.16.5.10|
|192.168.0.0 - 192.168.255.255|/16|192.168.1.100|

## 🔎 **Як дізнатись свою IP-адресу (в Linux)?**

```bash
ip a        # Показує локальну IP-адресу
curl ifconfig.me   # Зовнішня (публічна) IP-адреса
```

## 📥 **Як IP використовується?**

Коли ти відкриваєш сайт:
1. Твій ПК запитує DNS — яка IP-адреса в `google.com`
2. Отримує відповідь: `142.250.186.14`
3. Створюється IP-пакет до цього сервера
4. Відправка — маршрутизація — доставка!

## 🛡️ Для чого DevOps-інженеру знати про IP?

- Правильно налаштовувати сервери, кластери, хости
- Розгортати **Docker**, **Kubernetes** (CIDR для подів, сервісів)
- Працювати з **firewall**, **VPN**, **NAT**
- Налагоджувати з'єднання між **мережами, хмарами, клієнтами**
