**Питання: Як зупинити виконання PowerShell скрипта?**

**Опції:**  
a. Write in console cmdlet: `Pause-Script`  
b. Write in console cmdlet: `Stop-Process`  
c. Press: `Ctrl + C`  
d. Write in console cmdlet: `Suspend-Script`  
e. Write in console cmdlet: `Break-Execution`

---

**Правильна відповідь: c. Press: `Ctrl + C`**

---

**Пояснення:**

- **a. `Pause-Script`** — **Неправильно**, оскільки такого cmdlet'а в PowerShell **не існує**. Це вигадане ім’я.
- **b. `Stop-Process`** — **Неправильно**, цей cmdlet використовується для **завершення процесів за іменем або ID**, а не для безпосередньої зупинки скрипта. Потребує додаткової інформації про процес, тому не підходить для швидкої ручної зупинки.
- **c. `Ctrl + C`** — **Правильно**, це стандартна комбінація клавіш для **переривання виконання скрипта** у PowerShell (і в багатьох інших командних оболонках). Вона миттєво зупиняє скрипт.
- **d. `Suspend-Script`** — **Неправильно**, такого cmdlet'а також **не існує** в PowerShell.
- **e. `Break-Execution`** — **Неправильно**, це **вигаданий** cmdlet, якого немає серед стандартних команд PowerShell.


**Питання: Які з наступних cmdlet-ів використовуються для роботи з файлами у PowerShell?**

**Опції:**  
a. `Copy-Item`  
b. `Start-Item`  
c. `Get-ChildItem`  
d. `Move-Item`

---

**Правильна відповідь:**  
**a. Copy-Item**  
**c. Get-ChildItem**  
**d. Move-Item**

---

**Пояснення:**

- **a. `Copy-Item`** — **Правильно**, використовується для **копіювання файлів або папок** з одного місця в інше.
- **b. `Start-Item`** — **Неправильно**, такого cmdlet'а **немає** у PowerShell. Існує схожий `Invoke-Item`, який **відкриває файл або програму**, але це **не робота з файлами як об’єктами файлової системи** (копіювання, переміщення, тощо).
- **c. `Get-ChildItem`** — **Правильно**, повертає список файлів і папок у каталозі. Часто використовується для **перегляду вмісту директорій**.
- **d. `Move-Item`** — **Правильно**, використовується для **переміщення файлів або папок** у нове місце.


**Питання: Які з наступних cmdlet-ів використовуються для роботи з процесами у PowerShell?**

**Опції:**  
a. `Start-Process`  
b. `Stop-Process`  
c. `Remove-Process`  
d. `Get-Process`  
e. `Resume-Process`

---

**Правильна відповідь:**  
**a. Start-Process**  
**b. Stop-Process**  
**d. Get-Process**

---

**Пояснення:**

- **a. `Start-Process`** — **Правильно**, використовується для **запуску нового процесу**, наприклад програми або скрипта.
- **b. `Stop-Process`** — **Правильно**, дозволяє **завершити (вбити) процес** за його іменем або ID.
- **c. `Remove-Process`** — **Неправильно**, такого cmdlet'а **не існує** у PowerShell.
- **d. `Get-Process`** — **Правильно**, дозволяє **отримати інформацію про поточні процеси**, включаючи використання пам’яті, CPU тощо.
- **e. `Resume-Process`** — **Неправильно**, цього cmdlet'а **немає** серед стандартних команд PowerShell. PowerShell не має вбудованої команди для відновлення призупиненого процесу (це складніше на рівні ОС).

**Питання: Які з наступних операторів порівняння використовуються у PowerShell?**

**Опції:**  
a. `-lt`  
b. `-like`  
c. `-gt`  
d. `-eq`  
e. `-ne`

---

**Правильна відповідь:**  
**a. -lt**  
**b. -like**  
**c. -gt**  
**d. -eq**  
**e. -ne**

---

**Пояснення:**

Усі ці оператори — **дійсні оператори порівняння в PowerShell**:

- **a. `-lt` (less than)** — **менше**, використовується для числового порівняння:  
    `5 -lt 10` → `True`
    
- **b. `-like`** — **порівняння рядків з шаблоном** (використовує `*` як wildcard):  
    `"file.txt" -like "*.txt"` → `True`
    
- **c. `-gt` (greater than)** — **більше**:  
    `20 -gt 15` → `True`
    
- **d. `-eq` (equals)** — **дорівнює**:  
    `"apple" -eq "apple"` → `True`
    
- **e. `-ne` (not equal)** — **не дорівнює**:  
    `1 -ne 2` → `True`


**Питання: Яка команда (Linux-команда) використовується для відображення поточної директорії у PowerShell?**

---

**Правильна відповідь:**  
`pwd`

---

**Пояснення:**

- У PowerShell підтримується команда **`pwd`** (скорочено від _print working directory_), яка показує **поточну робочу директорію**, подібно як у Linux.
    
- PowerShell також має еквівалентний cmdlet:
    ```powershell
		Get-Location
	```
    Але для зручності та сумісності з Unix-подібними системами підтримується `pwd`.

**Питання: Який оператор використовується для об'єднання рядків у PowerShell?**

---

**Правильна відповідь:**  
**`+` (плюс)**

---

**Пояснення:**

У PowerShell для **конкатенації (об'єднання) рядків** використовується оператор **`+`**, як і в багатьох інших мовах програмування.

📌 **Приклад:**

```powershell
$firstName = "Ivan"
$lastName = "Petrenko"
$fullName = $firstName + " " + $lastName
Write-Output $fullName
```

🔎 Виведе: `Ivan Petrenko`


**Питання: Який cmdlet використовується для створення нового текстового файлу у PowerShell?**

---

**Правильна відповідь:**  
**`New-Item`**

---

**Пояснення:**

У PowerShell для створення нового текстового файлу використовується команда:

powershell

CopyEdit

`New-Item -Path "example.txt" -ItemType "File"`

🔎 Це створить новий файл `example.txt` у поточній директорії.

📌 **Приклад з вмістом:**  
Якщо ти хочеш одразу створити файл із вмістом, зручніше використовувати:

```powershell
"Hello, world!" | Out-File -FilePath "example.txt"
```

Або:

```powershell
Set-Content -Path "example.txt" -Value "Hello, world!"
```
