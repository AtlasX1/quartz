## 📦 Образи (Images)

| Команда                    | Опис                              |
| -------------------------- | --------------------------------- |
| `docker pull <image>`      | Завантажити образ із Docker Hub   |
| `docker images`            | Показати список локальних образів |
| `docker rmi <image>`       | Видалити образ                    |
| `docker build -t <name> .` | Створити образ з Dockerfile       |

---
## 🐳 Контейнери (Containers)

| Команда                                           | Опис                                           |
|---------------------------------------------------|------------------------------------------------|
| `docker run <image>`                             | Запустити контейнер з образу                  |
| `docker run -d -p 8080:80 --name <name> <image>` | Запустити у фоні з пробросом портів           |
| `docker ps`                                      | Список запущених контейнерів                  |
| `docker ps -a`                                   | Список усіх контейнерів                       |
| `docker stop <container>`                        | Зупинити контейнер                            |
| `docker start <container>`                       | Запустити зупинений контейнер                 |
| `docker restart <container>`                     | Перезапустити контейнер                       |
| `docker rm <container>`                          | Видалити контейнер                            |

---
## 🛠 Інтерактивна робота

| Команда                                       | Опис                                           |
|-----------------------------------------------|------------------------------------------------|
| `docker exec -it <container> bash`           | Відкрити Bash всередині контейнера            |
| `docker logs <container>`                    | Показати логи контейнера                      |

---
## 📁 Volumes (Томи)

| Команда                             | Опис                                           |
|-------------------------------------|------------------------------------------------|
| `docker volume create <name>`      | Створити том                                  |
| `docker volume ls`                 | Переглянути список томів                      |

---
## 🌐 Networks (Мережі)

| Команда                              | Опис                                           |
|--------------------------------------|------------------------------------------------|
| `docker network create <name>`      | Створити нову мережу                          |
| `docker network ls`                 | Переглянути мережі                            |
