### 🧠 Що таке Kubernetes?

**Kubernetes** (часто скорочено як **K8s**) — це **система для автоматизації розгортання, масштабування та управління контейнеризованими застосунками**.

Він був створений у Google і тепер підтримується Cloud Native Computing Foundation (CNCF). Kubernetes допомагає керувати великою кількістю контейнерів (наприклад, Docker) у кластері серверів.

---

### 🧰 Основні компоненти Kubernetes:

1. **Pod** – найменша одиниця в K8s, яка містить один або кілька контейнерів.
2. **Node** – окремий сервер (віртуальний або фізичний), на якому працюють Pod-и.
3. **Cluster** – набір Node-ів, якими управляє Kubernetes.
4. **Deployment** – описує, як створювати та оновлювати Pod-и.
5. **Service** – стабільна IP-адреса для доступу до Pod-ів, навіть якщо ті перезапускаються.
6. **ConfigMap / Secret** – спосіб зберігати конфігурацію та чутливі дані.

---

### 📦 Навіщо потрібен Kubernetes?

- Автоматично **відновлює** контейнери, які впали.
- **Масштабує** застосунок за потреби (вгору або вниз).
- **Розподіляє навантаження** між Pod-ами.
- Дає можливість **безперервного оновлення** (rolling updates).

## 🔰 **1. Передумови (базові знання)**

Перед стартом впевнись, що добре розумієш:

- 🔹 **Linux**: команди bash, робота з файлами, мережа.
- 🔹 **Docker**: створення образів, запуск контейнерів.
- 🔹 **YAML**: синтаксис конфігураційних файлів.

---

## 🚀 **2. Встановлення середовища**

Вибери зручний спосіб для запуску Kubernetes локально:

- ✅ **Minikube** — найпопулярніший варіант для навчання.
    `minikube start kubectl get nodes`
    
- 🔹 **K3s** — легкий Kubernetes від Rancher, підходить для слабших машин.
    
- 🔹 **Kind (Kubernetes IN Docker)** — Kubernetes кластери в Docker.

---

## 📚 **3. Основи Kubernetes (ключові поняття)**

Вивчи базові об'єкти:

|Об'єкт|Що робить|
|---|---|
|`Pod`|Найменша одиниця, що містить контейнери|
|`Service`|Доступ до Pod-ів|
|`Deployment`|Масштабування та оновлення Pod-ів|
|`ConfigMap`|Зберігає конфігурацію у змінних|
|`Secret`|Зберігає чутливі дані|
|`Namespace`|Розділення середовищ|

---

## 🧪 **4. Практика з kubectl**

Працюй через CLI:

```bash
kubectl create deployment nginx --image=nginx
kubectl expose deployment nginx --port=80 --type=NodePort
kubectl get all
kubectl delete deployment nginx
```

## 🏗️ **6. Проекти для практики**

- Напиши свій `Deployment` YAML.
    
- Створи `Service`, щоб підключитись до Pod-ів.
    
- Додай `ConfigMap` для налаштувань.
    
- Розгортай прості застосунки (наприклад, Nginx, Redis, Node.js API).
