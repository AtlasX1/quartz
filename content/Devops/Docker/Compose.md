
Docker Compose - це інструмент для визначення та запуску багатоконтейнерних Docker-додатків. Він дозволяє розробникам визначати всі сервіси, мережі та томи, необхідні для багатоконтейнерного додатку, в одному файлі docker-compose.yml. 

За допомогою Docker Compose ви можете легко керувати розгортанням складних додатків, що складаються з декількох взаємопов'язаних контейнерів. Це спрощує такі завдання, як запуск контейнерів, масштабування сервісів та керування залежностями між контейнерами. 

Docker Compose надає простий спосіб описати та організувати інфраструктуру вашого додатку, полегшуючи роботу з багатоконтейнерними налаштуваннями та забезпечуючи узгоджене розгортання в різних середовищах.

Звісно! Ось **таблиця з основними командами `docker-compose`**:

| Команда                              | Опис                                               |
| ------------------------------------ | -------------------------------------------------- |
| `docker-compose up`                  | Запускає всі сервіси з `docker-compose.yml`        |
| `docker-compose up -d`               | Запускає сервіси у фоновому режимі (detached mode) |
| `docker-compose down`                | Зупиняє і **видаляє** контейнери, мережі, томи     |
| `docker-compose stop`                | Лише зупиняє контейнери                            |
| `docker-compose restart`             | Перезапускає всі сервіси                           |
| `docker-compose logs`                | Виводить логи всіх сервісів                        |
| `docker-compose logs -f`             | Виводить логи в реальному часі (follow mode)       |
| `docker-compose ps`                  | Показує список запущених контейнерів               |
| `docker-compose exec <service> bash` | Відкриває bash-сесію всередині вказаного сервісу   |
| `docker-compose build`               | Будує образи на основі `Dockerfile`                |
| `docker-compose up --build`          | Будує і запускає сервіси одночасно                 |
