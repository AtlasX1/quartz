### 🔹 Що таке Docker?

**Docker** — це платформа для створення, доставки та запуску застосунків у **контейнерах**.

#### 🔸 Аналогія

Уяви, що тобі потрібно відправити програму іншій людині. Замість того, щоб казати: "Встанови Python, потім Flask, потім таку версію бібліотеки..." — ти просто даєш йому запаковану коробку, яка **вже містить все необхідне**. Він просто відкриває коробку і запускає програму — все працює.

Ця "коробка" — це **контейнер Docker**.

Docker - це платформа для розробки, транспортування та запуску додатків у легких, портативних та самодостатніх контейнерах. Ці контейнери інкапсулюють усі залежності та бібліотеки, необхідні для роботи програми, забезпечуючи узгодженість та відтворюваність у різних середовищах, від розробки до виробництва. Docker став популярним інструментом для контейнеризації, що дозволяє розробникам ефективно створювати, розгортати та керувати додатками. Він спрощує процес пакування, розповсюдження та масштабування додатків, полегшуючи роботу зі складними програмними системами та архітектурами мікросервісів. Контейнери Docker ізольовані один від одного та від хост-системи, забезпечуючи безпечне та узгоджене середовище для запуску додатків.

---

### 🔹 Основні поняття

#### ✅ Контейнер

> Контейнер — це легкий, ізольований процес, який містить все необхідне для запуску програми: код, бібліотеки, середовище, залежності.

#### ✅ Образ (Image)

> Образ — це шаблон, з якого створюється контейнер. Це наче "рецепт", за яким можна зібрати контейнер.

#### ✅ Dockerfile

> Dockerfile — це текстовий файл, у якому описано, як створити Docker-образ. Він містить інструкції: яку базову систему брати, що встановлювати, які файли копіювати тощо.

---

### 🔹 Як це працює?

1. **Ти пишеш Dockerfile**
    
2. **Створюєш образ**: `docker build`
    
3. **Запускаєш контейнер** з образу: `docker run`
    
4. **Контейнер працює ізольовано**, незалежно від твоєї системи

### 🔹 Чому Docker — це круто?

- 🌍 Працює **на будь-якому сервері**
    
- 🧪 Ідеальний для **тестування**
    
- 🧹 Вирішує проблему "на моїй машині працює"
    
- 📦 Спрощує **доставку** застосунків
    
- 🔒 Забезпечує **ізоляцію** середовищ

### 🔹 Часті питання

**🔸 Чим Docker відрізняється від віртуальної машини?**

|Docker|Віртуальна машина|
|---|---|
|Легкий, швидкий старт|Повноцінна ОС, повільний запуск|
|Споживає менше ресурсів|Більше RAM/CPU|
|Використовує ядро хост-системи|Має власне ядро|
