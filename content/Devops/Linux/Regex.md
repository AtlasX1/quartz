### 🧠 **Що таке регулярні вирази?**

**Регулярний вираз (regex)** — це спеціальний шаблон (pattern), який використовується для пошуку або заміни тексту. Він дозволяє описати, які саме символи, слова чи структури ти хочеш знайти у рядку.

Це дуже потужний інструмент для обробки тексту, який часто використовується в DevOps, програмуванні, логах, CI/CD скриптах і навіть у текстових редакторах (наприклад, VS Code або Notepad++).

### 🔧 **Приклад простого regex:**

```
\d{3}
```

📝 Що означає:

- `\d` — цифра від 0 до 9.
- `{3}` — рівно три рази.

🔍 Тобто, цей вираз знайде **будь-яку послідовність із трьох цифр**, наприклад `123`, `456`, `789`


### 📦 Де використовують regex:

- 🔍 Пошук у текстах або логах (наприклад, у `grep` чи `awk`)
- 🔄 Заміна частин рядків (наприклад, у `sed`)
- ✅ Валідація (перевірка) вводу (наприклад, електронна пошта, номер телефону)
- 🧪 Тестування шаблонів у скриптах чи консолі


## 🧰 **Де в Linux використовуються regex**

У більшості інструментів командного рядка, зокрема:

|Команда|Призначення|
|---|---|
|`grep`|Пошук рядків у файлі або виводі|
|`sed`|Заміна тексту за шаблоном|
|`awk`|Потужна обробка текстових даних|
|`find`, `ls`, `ps`|Фільтрація результатів|
## 🔎 **Типи регулярних виразів у Linux**

### 1. **Basic Regular Expressions (BRE)**

Використовується за замовчуванням у `grep`.
- `.` — будь-який символ
- `*` — 0 або більше повторень
- `^` — початок рядка
- `$` — кінець рядка

> 🔹 Наприклад: `grep "^abc"` — шукає рядки, що починаються з `abc`.

### 2. **Extended Regular Expressions (ERE)**

Використовується в `egrep` або `grep -E`.
- Додаткові можливості: `+`, `?`, `|`, `()`

> 🔹 Наприклад: `grep -E "(cat|dog)"` — знайде `cat` або `dog`.

### 3. **Perl Compatible Regular Expressions (PCRE)**

Використовується в `grep -P`, `perl`, `python`, тощо.

> 🔹 Приклад: `grep -P "\d{2,4}"` — знайде 2-4 цифри підряд.

## 🧪 **Приклади з практики**

### 🔹 `grep` — Пошук за regex

```
grep "error.*code" log.txt
```

Знайде всі рядки у `log.txt`, де є слово `error`, за яким іде будь-який текст, а потім — `code`.

---

### 🔹 `sed` — Заміна тексту за regex

```
sed -E 's/[0-9]{4}/####/g' data.txt
```

Заміна всіх 4-значних чисел на `####`.

---

### 🔹 `awk` — Витягування даних з рядків

```
awk '/^[a-z]+@[a-z]+\.[a-z]{2,4}$/' emails.txt
```

Знайде всі рядки, які виглядають як email.

4. **Використовуй групування `()` і класи символів `[]` з обережністю** — слідкуй за тим, що саме захоплюється виразом

## 🧩 Основи групування

### 📌 Синтаксис:

`(...) — група`

Все, що знаходиться всередині дужок, вважається **єдиною одиницею**.

🔍 **Групування в регулярних виразах** — це одна з найпотужніших фіч, яка дозволяє:

1. **Об'єднувати частини шаблону** (наприклад, щоб застосувати до них кількість повторень).
2. **Захоплювати групи символів** для подальшого використання.
3. **Створювати логіку "АБО" всередині частини шаблону**.

## 📘 Приклади базового групування

### 🔹 Приклад 1 — кілька повторів групи

```
(ab)+
```

🔍 Знайде: `ab`, `abab`, `ababab`

> Тут `+` застосовується до всієї групи `(ab)`

---

### 🔹 Приклад 2 — логічне "АБО" в групі

```
(cat|dog)
```

🔍 Знайде або `cat`, або `dog`

> Символ `|` працює як "або", тільки **всередині групи**

---

### 🔹 Приклад 3 — використання груп у `sed` або `bash`

```
echo "abc123" | sed -E 's/(abc)(123)/\2-\1/
```

🔄 Результат: `123-abc`

> `\1`, `\2` — це **порядкові номери груп**, які можна викликати

---

## 🧠 Типи групування

|Тип|Синтаксис|Опис|
|---|---|---|
|Захоплююча|`(abc)`|Створює групу і зберігає її значення|
|Незахоплююча|`(?:abc)`|Групує, але не зберігає|
|Іменована|`(?P<name>abc)` (Python)|Зручно використовувати по імені|
|Погляди (lookahead/behind)|`(?=...)`, `(?<=...)`|Логічна перевірка без захоплення|

---

## 🧪 Захоплення груп (capturing groups)

Використовується, коли потрібно отримати значення з тексту.

### Приклад у Bash:

```
echo "2024-04-07" | sed -E 's/([0-9]{4})-([0-9]{2})-([0-9]{2})/Day: \3, Month: \2, Year: \1/'
```

🔄 Результат: `Day: 07, Month: 04, Year: 2024`

---

## 🧪 Іменовані групи (у Python):
```
import re
match = re.search(r'(?P<user>\w+)@(?P<domain>\w+)\.com', "john@example.com")
print(match.group('user'))   # john
print(match.group('domain')) # example
```

---

## 📌 Практичні підказки

- Використовуй групи для структурованого пошуку в логах (`grep`, `awk`)
- Комбінуй з `\1`, `\2` у `sed`, щоб зробити заміну місцями
- Вважай на вкладені групи: `((a)(b))` → 3 групи!

|Опція|Опис|
|---|---|

## 📦 **Приклади DevOps-задач із `grep`**

### 🔹 **1. Пошук помилок у логах**

```
grep -i 'error' /var/log/syslog
```

Знайде всі згадки про `error` (незалежно від регістру).

```
grep -Eo '([0-9]{1,3}\.){3}[0-9]{1,3}' nginx.log
```

- `-o` — виводити лише збіги (а не весь рядок)

### 🔹 **3. Пошук користувачів з іменем "admin" в системі**

```
grep -E '^admin:' /etc/passwd
```

Знайде рядки, що починаються з `admin:` у файлі користувачів.

### 🔹 **4. Знайти рядки з певним шаблоном у CI/CD логах**

```
grep -E 'Build (started|finished)' cicd.log
```

Знайде всі рядки про старт або завершення білда.

---

### 🔹 **5. Показати лог подій навколо помилки**
```
grep -C 2 'ERROR' app.log
```

Показує по 2 рядки **до і після** кожної помилки.

## 🧰 Що таке `sed`?

**`sed` (stream editor)** — це потужна утиліта командного рядка для **обробки текстових даних**. Вона читає вхідний потік рядків (файл або stdin) і виконує над ними операції, зокрема:

- 🔄 пошук і заміну тексту
- ✂️ видалення рядків
- ✍️ вставку тексту
- 🧪 використання регулярних виразів для модифікації даних

---

## 🛠 Базовий синтаксис

```
sed [опції] 'операція' файл
```

---

## 🔁 Найчастіше вживана команда — `s` (заміна)

### 📌 Синтаксис:

```
sed 's/шаблон/заміна/опції
```
### ✏️ Опції:

- `g` — замінити **всі** входження в рядку
- `i` — ігнорувати регістр
- `p` — виводити замінені рядки (з `-n`)
- `e` — виконати як shell-команду

---

## 📘 Приклади з `sed` у DevOps

---

### 🔹 **1. Заміна в рядку**

```
echo "Hello world" | sed 's/world/DevOps/'
```

🔁 Вихід: `Hello DevOps`

---

### 🔹 **2. Заміна всіх входжень в рядку**
```
echo "a,b,c,d" | sed 's/,/-/g'
```

🔁 Вихід: `a-b-c-d`

---

### 🔹 **3. Видалення порожніх рядків у файлі**

```
sed '/^$/d' file.txt
```

🔍 Видаляє всі рядки, які повністю порожні.

---

### 🔹 **4. Видалити коментарі у конфігах (рядки, що починаються з #)**

```
sed '/^#/d' nginx.conf
```

---

### 🔹 **5. Заміна тексту в файлі in-place**

```
sed -i 's/localhost/127.0.0.1/g' config.yml
```

📄 Змінює всі `localhost` на `127.0.0.1` у файлі.

---

### 🔹 **6. Вставити текст після певного рядка**

```
sed '/pattern/a New line here' file.txt
```

📝 Вставить `New line here` після рядка, який містить `pattern`.

---

### 🔹 **7. Витягнути значення по regex**

```
echo "version=1.2.3" | sed -E 's/^version=([0-9\.]+)/\1/'
```

🔍 Витягує номер версії: `1.2.3`

---

## 🔗 Приклад з DevOps-практики

### 🧪 Оновлення версії в YAML:

```
sed -i -E 's/(version:\s*)".+"/\1"2.0.0"/' deployment.yaml
```

Замінює рядок `version: "1.0.0"` на `version: "2.0.0"`.

---

### 🧰 Поради:

- Використовуй `-E` для зручнішого синтаксису (extended regex)
- Завжди тестуй без `-i` спочатку, щоб не зіпсувати файли
- `sed` дуже швидкий — підходить для обробки великих логів

## 🧾 Щоб змінити файл-джерело, потрібно додати опцію `-i`

### 📌 `-i` (in-place) — модифікує файл без створення копії:

```
sed -i 's/localhost/127.0.0.1/g' config.yaml
```

✅ Це **змінить файл `config.yaml` напряму**, замінюючи всі `localhost` на `127.0.0.1`.

---

## 🧷 Безпечно: створення резервної копії

Ти можеш створити **беккап-файл** перед зміною, додавши розширення до `-i`:

```
sed -i.bak 's/localhost/127.0.0.1/g' config.yaml
```

📁 Це створить копію: `config.yaml.bak`, а змінить `config.yaml`.

---

## 🛠 Якщо не використовувати `-i`

```
sed 's/localhost/127.0.0.1/g' config.yaml
```

🔍 Просто виведе змінений вміст у термінал, **але файл не зміниться**.

---

## 🧠 Порада DevOps-інженера:

Завжди перевіряй команду `sed` **без `-i` спочатку**, щоб переконатися, що regex працює правильно. Наприклад:
```
sed -n 's/localhost/127.0.0.1/p' config.yaml
```

А вже потім:
```
sed -i 's/localhost/127.0.0.1/g' config.yaml
```
