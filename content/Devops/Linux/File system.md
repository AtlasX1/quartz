У Linux усе — **файл**.

## 📂 Основна структура файлової системи Linux

Коренева директорія — це **`/`**, з якої починається **все дерево файлів**:
```
/
├── bin
├── boot
├── dev
├── etc
├── home
├── lib
├── media
├── mnt
├── opt
├── proc
├── root
├── run
├── sbin
├── srv
├── sys
├── tmp
├── usr
└── var
```

---
## 🗂 Опис основних каталогів

|Каталог|Призначення|
|---|---|
|`/`|Корінь всієї файлової системи|
|`/bin`|**Basic BINaries** – основні команди, доступні всім (наприклад: `ls`, `cp`)|
|`/sbin`|**System BINaries** – системні утиліти (тільки для root), напр. `reboot`|
|`/etc`|Конфігураційні файли (наприклад: `/etc/hosts`, `/etc/nginx/nginx.conf`)|
|`/home`|Домашні директорії користувачів (`/home/user`)|
|`/root`|Домашня директорія користувача root|
|`/lib`, `/lib64`|Системні бібліотеки, які потрібні для запуску бінарників у `/bin` та `/sbin`|
|`/usr`|Програми та бібліотеки, які не є критичними для запуску системи|
|`/opt`|Опційне ПЗ, часто сторонні додатки|
|`/var`|**VARiable** файли: логи (`/var/log`), кеш, спулі|
|`/tmp`|Тимчасові файли. Очищується після перезавантаження|
|`/boot`|Завантажувач системи (GRUB), ядро (`vmlinuz`)|
|`/dev`|Файли пристроїв (наприклад: `/dev/sda1`, `/dev/null`)|
|`/proc`|Віртуальна файлова система – інформація про процеси та систему|
|`/sys`|Ще одна віртуальна система – інтерфейс до ядра|
|`/media`|Монтування знімних носіїв (USB, CD)|
|`/mnt`|Тимчасове монтування файлових систем вручну|
|`/run`|Змінні файли, які створюються при запуску системи|

## 🧪 Корисні команди для роботи з файловою системою

```
# Перевірити, скільки місця займають каталоги
du -sh /var/*

# Переглянути структуру каталогів у вигляді дерева
tree /

# Перевірити скільки вільного місця на диску
df -h

# Подивитися деталі про конкретний файл
ls -l /etc/hosts

# Пошук файлів за іменем
find /etc -name "*.conf"

# Монтування/розмонтування (монтаж знімного диску наприклад)
sudo mount /dev/sdb1 /mnt
sudo umount /mnt
```

## 💡 DevOps-порада:

Найчастіше ти будеш працювати з:

- `/etc/` — налаштування сервісів.
    
- `/var/log/` — логи додатків та системи.
    
- `/home/` — домашні файли користувачів.
    
- `/usr/local/bin` — власні скрипти/утиліти.
