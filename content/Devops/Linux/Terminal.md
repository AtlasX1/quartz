**Термінал Linux** — це головний інструмент DevOps-інженера. Він дозволяє керувати системою, писати скрипти, запускати сервіси, встановлювати пакети — **все це робиться через текстовий інтерфейс**.

## 💻 Що таке термінал?

**Термінал** — це програма, яка дозволяє взаємодіяти з операційною системою за допомогою **командного рядка** (CLI — Command Line Interface).

У терміналі ти спілкуєшся з **оболонкою (shell)**. Найпопулярніша оболонка в Linux — це **Bash** (`Bourne Again SHell`), але є й інші: `zsh`, `fish`, `sh`.

---

## 🌟 Чому термінал такий важливий?

🔹 **Легкий** — не вимагає багато ресурсів  
🔹 **Гнучкий** — можна автоматизувати завдання за допомогою скриптів  
🔹 **Потужний** — доступ до всіх системних можливостей  
🔹 **Швидкий** — багато речей робляться швидше, ніж через GUI

## 🛠 Основні команди терміналу Linux

### 📁 Робота з файлами і каталогами

```
pwd                 # показати поточний каталог
ls                  # вивести список файлів
ls -la              # детальний список (з прихованими файлами)
cd /шлях/до/каталогу # перейти в інший каталог
mkdir ім’я_каталогу # створити новий каталог
touch файл.txt      # створити новий порожній файл
cp файл1 файл2      # копіювати файл
mv файл нове_ім’я   # перемістити або перейменувати файл
rm файл.txt         # видалити файл
rm -r каталог       # видалити каталог з усім вмістом
```
### 📄 Перегляд вмісту файлів

```
cat файл.txt        # показати весь вміст файлу
less файл.txt       # перегляд з прокруткою
head -n 10 файл.txt # перші 10 рядків
tail -n 20 файл.txt # останні 20 рядків
```
### 🧾 Робота з правами доступу

```
chmod 755 файл.sh      # змінити права доступу
chown user:group файл  # змінити власника файлу
```
### 📦 Робота з пакетами (для Ubuntu/Debian)

```
sudo apt update                 # оновити список пакетів
sudo apt install ім’я_пакету   # встановити пакет
sudo apt remove ім’я_пакету    # видалити пакет
```
### 🧠 Інформація про систему

```
uname -a         # загальна інформація про систему
top              # активні процеси в реальному часі
df -h            # інформація про диски
free -m          # використання оперативної пам’яті
ps aux           # всі процеси
whoami           # ім’я поточного користувача
```

## 🧪 Бонус: простий скрипт Bash

```
#!/bin/bash
echo "Привіт, $USER!"
echo "Сьогоднішня дата: $(date)"
```

Збережи цей код у файл `hello.sh`, зроби його виконуваним:

```
chmod +x hello.sh
./hello.sh
```
