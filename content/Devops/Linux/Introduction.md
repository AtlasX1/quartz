## 🐧 Що таке Linux?

**Linux** — це вільна й відкрита операційна система, яка базується на ядрі Linux (Linux kernel). Її створив Лінус Торвальдс у 1991 році. Вона стала основою для багатьох **дистрибутивів** — це різні "смаки" Linux з власними особливостями.

## 🌟 Особливості Linux:

🔹 **Відкритий код (Open Source)** – будь-хто може переглядати, змінювати й використовувати код.

🔹 **Стабільність і надійність** – не потребує частих перезавантажень, витримує великі навантаження.

🔹 **Безпека** – має гнучку систему прав доступу, постійно оновлюється.

🔹 **Масштабованість** – використовується і на Raspberry Pi, і на суперкомп’ютерах.

🔹 **Популярний у DevOps** – більшість серверів, хмарних платформ і контейнерів працюють на Linux.

## 📦 Популярні дистрибутиви Linux і їх призначення

### 🟢 Ubuntu

- **Призначення:** навчання, десктоп, сервери, DevOps.
- **Плюси:** зручний, велика спільнота, багато документації.
- **Смак:** є **Ubuntu Server** — без GUI, ідеально для серверів.

### 🔴 Debian

- **Призначення:** стабільні сервери, критичні системи.
- **Плюси:** надзвичайно стабільний, але оновлення повільні.
- **Основа для:** Ubuntu.

### 🔵 CentOS / AlmaLinux / Rocky Linux

- **Призначення:** корпоративні сервери.
- **Плюси:** сумісні з Red Hat Enterprise Linux (RHEL).
- **CentOS:** більше не оновлюється, замінений на **AlmaLinux** або **Rocky Linux**.

### 🟣 Arch Linux

- **Призначення:** ентузіасти, кастомізація.
- **Плюси:** максимальний контроль, завжди найновіше ПЗ.
- **Мінус:** складний для новачків.

### ⚫ Kali Linux

- **Призначення:** етичний хакінг, кібербезпека.
- **Плюси:** попередньо встановлені інструменти пентестингу.

### 🐳 Alpine Linux

- **Призначення:** Docker контейнери.
- **Плюси:** надзвичайно легка, маленький розмір (~5MB), швидка.

## 🧪 Приклад: команди Linux

```
# Перегляд вмісту каталогу
ls -la

# Переход до каталогу
cd /etc

# Перевірка версії дистрибутиву
cat /etc/os-release

# Встановлення пакету (для Ubuntu/Debian)
sudo apt update && sudo apt install htop

# Перезапуск служби
sudo systemctl restart nginx
```

## 💡 У DevOps зазвичай використовують:

- **Ubuntu Server** – проста та популярна.
- **Debian** – для довготривалих проєктів.
- **Alpine Linux** – для контейнерів Docker.
- **CentOS → AlmaLinux** – у великих компаніях.
